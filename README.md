# Tyler Smith: Portfolio

Personal site for Tyler Smith, iOS developer and Computer Science student at LaGuardia Community College (CUNY).

**Live site:** [codewithty.github.io/portfolio-tyler](https://codewithty.github.io/portfolio-tyler/)

## About the site

The hero is an iPhone lock screen set to 9:41, the time Apple shows in its product shots. Each notification is something I've shipped, at What's The Move (a live SwiftUI and Supabase events app) and at the Air Force Research Laboratory.

- Plain HTML, CSS, and JavaScript, with no framework or build step
- Projects are rendered from a JavaScript array in `script.js`, so adding one is a single object
- Light and dark themes, following the device setting with a manual toggle
- Responsive down to phone width, keyboard-accessible, and respects reduced-motion settings
- Hosted on GitHub Pages

## Run it locally

Open `index.html` in a browser. No install needed.
